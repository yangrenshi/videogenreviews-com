# VideoGenReviews Web

The official static Astro website for [videogenreviews.com](https://videogenreviews.com).

## Tech Stack
- **Framework**: Astro 5.x (SSG)
- **Styling**: Tailwind CSS
- **SEO**: `@astrojs/sitemap`, Open Graph, JSON-LD Schema (FAQPage, Review, Breadcrumbs)

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Output will be generated in `dist/`.
